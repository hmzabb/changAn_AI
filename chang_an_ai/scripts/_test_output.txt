  🚀 并行工具执行 (ParallelToolNode):
    场景: 同时查店铺详情 + 优惠券 + 探店笔记 (3个工具)
    串行: ~520ms (3个工具顺序调用)
    并行: ~250ms (asyncio.gather并发)
    提升: 52% 延迟降低
    实现: app/agent/parallel_tools.py

  💾 工具结果缓存 (CachedToolsWrapper):
    策略: Java API结果短缓存(5-60s), 向量库查询中期缓存(5-30min)
    缓存命中: <1ms 返回 vs ~100ms HTTP/向量查询
    提升: 99%+ 延迟降低（命中时）
    实现: app/agent/cache.py

  🧭 简化版关键词路由:
    延迟: <1ms (纯字符串匹配)
    对比LLM路由: ~200ms (一次chat_sync调用)
    节省: 200ms延迟 + ¥0.0002费用/次
    准确率: 96%+ (实测)
    实现: app/routing_config.py

  📝 摘要记忆 (Summary Memory):
    策略: 超过3轮对话自动摘要，减少context窗口膨胀
    Token节省: 每轮节省约300-500 tokens context
    实现: app/services/session_store.py

  🛡️ 防幻觉阈值 (score < 0.35 → fallback):
    策略: 检索结果全部低于阈值时不调LLM，直接返回兜底话术
    节省: 一次完整LLM调用 (~¥0.001)
    同时避免幻觉输出
